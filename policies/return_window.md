# Return Window

Most items can be returned for any reason within 14 days of the delivery date,
provided the item is unworn/unopened and in its original packaging. Electronics
must be returned within 21 days due to manufacturer resale restrictions. Return
shipping is free for defective items; for change-of-mind returns, a flat $5.99
return shipping fee is deducted from the refund unless the customer holds an
active Plus subscription, in which case return shipping is always free.
